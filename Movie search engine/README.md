# Movie Search Engine - Vanilla JS & API

Un buscador de películas en tiempo real que consume datos de una API externa para mostrar información detallada sobre cine.

## Características principales
* **Consumo de API:** Integración con [Nombre de la API, ej. OMDb API] mediante `fetch`.
* **Búsqueda Dinámica:** Filtrado de resultados según la entrada del usuario.
* **Manejo de Promesas:** Uso de `Async/Await` para gestionar la asincronía de forma limpia.

## Tecnologías
* **JavaScript Puro:** Lógica de búsqueda y renderizado de tarjetas.
* **CSS Flexbox/Grid:** Para un diseño responsivo y visualmente atractivo.
* **HTML5:** Estructura semántica para mejor SEO.
