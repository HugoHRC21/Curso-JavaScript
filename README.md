# 🚀 JavaScript Learning Journey - Hugo Rivas

¡Bienvenido a mi repositorio de aprendizaje de **JavaScript**! Aquí encontrarás una colección de proyectos prácticos que he desarrollado para dominar la lógica de programación, el manejo del DOM, el consumo de APIs y la creación de interfaces interactivas.

## Índice de Proyectos
Cada carpeta contiene un proyecto único con su propia documentación y lógica. Puedes probar las versiones en vivo (Live Demos) a continuación:

### Juegos y Lógica
* [🐍 Snake Game](https://hugohrc21.github.io/Curso-JavaScript/Snake%20game/) - El clásico juego con manejo de colisiones.
* [🧠 Interactive Quiz](https://hugohrc21.github.io/Curso-JavaScript/Quiz/) - Cuestionario dinámico con feedback en tiempo real.
* [🎲 Juego de Adivinanzas](https://hugohrc21.github.io/Curso-JavaScript/Juego%20de%20Adivinanzas/) - Lógica de azar y manejo de estados.

### APIs y Datos
* [🐙 PokeDex](https://hugohrc21.github.io/Curso-JavaScript/PokeDex/) - Consumo de la PokeAPI con `async/await`.
* [🎬 Movie Search Engine](https://hugohrc21.github.io/Curso-JavaScript/Movie%20Search%20Engine/) - Buscador de películas con peticiones asíncronas.
* [🎓 Student Grades](https://hugohrc21.github.io/Curso-JavaScript/student%20grades/) - Sistema de gestión de promedios académicos.

### Utilidades y Herramientas
* [🔢 Calculadora](https://hugohrc21.github.io/Curso-JavaScript/Calculadora/) - Operaciones matemáticas con interfaz limpia.
* [🔐 Password Generator](https://hugohrc21.github.io/Curso-JavaScript/Password%20Generator/) - Generador de claves seguras con manipulación de strings.
* [🕒 Digital Clock](https://hugohrc21.github.io/Curso-JavaScript/Digital%20Clock/) - Sincronización de tiempo en tiempo real.
* [📝 Mini To-Do App](https://hugohrc21.github.io/Curso-JavaScript/Mini%20To-Do%20App/) - Gestión de tareas con persistencia en `localStorage`.

### Multimedia y Diseño
* [🎵 Mini Reproductor](https://hugohrc21.github.io/Curso-JavaScript/Mini%20Reproductor/) - Interfaz de audio interactiva.
* [🔊 Playes Sound](https://hugohrc21.github.io/Curso-JavaScript/Playes%20Sound/) - Botonera de efectos de sonido.
* [✍️ Propiedades de Texto](https://hugohrc21.github.io/Curso-JavaScript/Propiedades%20de%20texto/) - Editor de estilos dinámico.
