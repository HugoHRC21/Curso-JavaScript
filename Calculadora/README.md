# Mini Calculator - Vanilla JavaScript

Una calculadora funcional desarrollada con **HTML5, CSS3 y JavaScript puro (ES6+)**. Este proyecto se enfoca en la manipulación del DOM y el manejo de lógica aritmética básica.

## Características
* **Operaciones Básicas:** Suma, resta, multiplicación y división.
* **Validación de Datos:** Manejo de errores para evitar la división por cero.
* **Interfaz Limpia:** Diseño minimalista enfocado en la usabilidad.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de Arrow Functions y desestructuración de arreglos para un código más moderno y legible.
* **HTML5 & CSS3:** Estructura semántica y diseño responsivo.

## Aprendizaje
* Captura de eventos con `addEventListener`.
* Conversión de tipos de datos (`parseFloat`) para asegurar cálculos precisos.
* Separación de la lógica de cálculo de la lógica de obtención de datos.
