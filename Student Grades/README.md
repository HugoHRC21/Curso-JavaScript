# Student Grades Management - Data Analysis & UI

Un sistema funcional para la gestión y cálculo de calificaciones académicas, desarrollado con **Vanilla JavaScript** para automatizar el procesamiento de promedios y estados escolares.

## Características principales
* **Cálculo Automático:** Procesamiento instantáneo de promedios finales basados en múltiples entradas de datos.
* **Lógica de Estado:** Determinación automática de estados (Aprobado/Reprobado) mediante condicionales dinámicos.
* **Interfaz de Datos:** Presentación organizada de resultados que facilita la lectura y el análisis del rendimiento académico.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de funciones matemáticas, manejo de arreglos de objetos y lógica de control de flujo.
* **HTML5:** Formularios validados para la entrada de datos numéricos.
* **CSS Moderno:** Estructura de tablas y contenedores diseñada para una visualización clara de reportes.

## Conocimientos Aplicados
* Manipulación de tipos de datos (Strings a Numbers) mediante `parseFloat` o `Number`.
* Uso de métodos de redondeo (`toFixed`) para asegurar la precisión en los resultados finales.
* Gestión de eventos de entrada para actualizar los cálculos sin necesidad de recargar la página.
