# Chronometer - Precision Timer in Vanilla JS

Un cronómetro funcional y preciso desarrollado con **JavaScript puro**, enfocado en el manejo de intervalos de tiempo y actualización dinámica de la interfaz de usuario.

## Características principales
* **Control Total:** Funciones de Inicio (Start), Pausa (Pause) y Reinicio (Reset).
* **Manejo de Tiempo:** Implementación lógica de milisegundos, segundos y minutos.
* **Interfaz Intuitiva:** Botones interactivos que responden al estado del cronómetro.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de `setInterval` para el conteo de tiempo y manipulación del DOM para reflejar los cambios en tiempo real.
* **HTML5 & CSS3:** Estructura limpia y diseño centrado para una mejor experiencia de usuario.

## Desafíos Técnicos
* Gestión de la memoria mediante el uso correcto de `clearInterval` para evitar fugas de rendimiento.
* Formateo de números para asegurar que el cronómetro siempre muestre dos dígitos (ej. 01, 02...).
