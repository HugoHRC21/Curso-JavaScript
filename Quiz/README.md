# Interactive Quiz App - Logic & Knowledge Assessment

Una aplicación de cuestionarios dinámica desarrollada con **Vanilla JavaScript**, diseñada para evaluar conocimientos mediante una interfaz interactiva y feedback inmediato.

## Características principales
* **Sistema de Puntuación:** Seguimiento en tiempo real de los aciertos y errores del usuario.
* **Feedback Dinámico:** Validación instantánea de respuestas con cambios visuales para indicar si la opción elegida es correcta.
* **Temporizador Integrado:** (Opcional) Lógica para limitar el tiempo de respuesta y aumentar el desafío.
* **Resultados Finales:** Pantalla de resumen detallada con la puntuación total al finalizar el cuestionario.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de arreglos de objetos para gestionar el banco de preguntas y lógica de comparación de respuestas.
* **DOM Manipulation:** Actualización constante de la interfaz para pasar de una pregunta a otra sin recargar la página.
* **CSS Moderno:** Diseño limpio y enfocado en la legibilidad para mejorar la concentración del usuario.

## Desafíos Técnicos
* Gestión del índice de preguntas para asegurar una navegación fluida.
* Implementación de lógica condicional para manejar el flujo del juego (inicio, progreso y fin).
* Manipulación de clases dinámicas para el feedback visual (verde para acierto, rojo para error).
