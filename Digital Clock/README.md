# Digital Clock - Real-Time Interface

Un reloj digital elegante y funcional que muestra la hora exacta del sistema en tiempo real, desarrollado íntegramente con **Vanilla JavaScript**.

## Características principales
* **Actualización en Tiempo Real:** Sincronización precisa cada segundo utilizando lógica asíncrona.
* **Formateo Automático:** Implementación de lógica para mostrar siempre dos dígitos (ej. 09:05:01) mediante métodos de strings.
* **Diseño Responsivo:** Interfaz adaptada para visualizarse correctamente en dispositivos móviles y escritorio.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso del objeto `Date` para obtener horas, minutos y segundos del sistema.
* **DOM Manipulation:** Actualización eficiente de los elementos de texto sin recargar la página.
* **CSS Moderno:** Uso de fuentes digitales y estilos minimalistas.

## Conocimientos Aplicados
* Manejo del ciclo de vida de la aplicación mediante `setInterval`.
* Concatenación y formateo dinámico de cadenas de texto (Template Literals).
