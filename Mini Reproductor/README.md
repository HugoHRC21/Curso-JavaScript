# Mini Music Player - Audio Interface

Un reproductor de audio dinámico y minimalista desarrollado con **Vanilla JavaScript**, que permite gestionar una lista de reproducción interactiva.

## Características principales
* **Control de Audio:** Funcionalidades de Play, Pause, Anterior y Siguiente.
* **Gestión de Playlist:** Carga dinámica de pistas y metadatos (título, artista, carátula).
* **Barra de Progreso:** Visualización en tiempo real del avance de la canción y capacidad de saltar a puntos específicos.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso extensivo de la API de Audio de HTML5 para el control del flujo multimedia.
* **Manipulación del DOM:** Actualización dinámica de elementos visuales sincronizados con el audio.
* **CSS Moderno:** Diseño de interfaz enfocado en la experiencia de usuario (UI/UX).

## Desafíos Técnicos
* Sincronización de eventos de tiempo (`timeupdate`) para actualizar la interfaz.
* Manejo de arreglos de objetos para la base de datos local de canciones.
