#Event Driven Programming

Un juego interactivo desarrollado para demostrar el dominio de los **eventos en JavaScript** y la lógica de validación en tiempo real.

##Características principales
* **Gestión de Eventos:** Implementación de diversos `EventListeners` (click, keydown) para capturar la entrada del usuario.
* **Lógica de Juego:** Sistema de validación que compara la entrada del usuario con un resultado generado aleatoriamente.
* **Feedback Dinámico:** Actualización inmediata de la interfaz para indicar si el usuario acertó o falló sin recargar la página.

##Tecnologías utilizadas
* **Vanilla JavaScript:** Uso intensivo de la API de eventos del DOM.
* **Control de Flujo:** Estructuras condicionales complejas para manejar los diferentes estados del juego (ganar, perder, intentar de nuevo).
* **CSS Dinámico:** Cambio de estilos mediante JS para resaltar aciertos o errores.

##Conocimientos Aplicados
* Capacidad para manejar la interactividad del usuario de forma fluida.
* Comprensión del ciclo de vida de un evento en el navegador.
* Manejo de la lógica de "Estado" (Score, intentos restantes, etc.).
