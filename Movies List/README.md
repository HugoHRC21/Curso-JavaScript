# Movies List - Personal Collection Manager

Una aplicación diseñada para gestionar colecciones personalizadas de cine, permitiendo al usuario organizar y visualizar sus películas favoritas mediante una interfaz dinámica en **Vanilla JavaScript**.

## Características principales
* **Gestión de Colecciones:** Funcionalidad para añadir y eliminar títulos de una lista personalizada.
* **Interfaz Visual:** Uso de tarjetas (cards) dinámicas para mostrar la información de cada película de forma atractiva.
* **Manejo de Arreglos:** Implementación de lógica de filtrado y almacenamiento de datos mediante estructuras de objetos en JS.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Manipulación del DOM para la creación dinámica de elementos de lista.
* **CSS Grid/Flexbox:** Diseño responsivo para asegurar que la colección se vea bien en cualquier dispositivo.
* **HTML5:** Marcado semántico para una estructura de datos clara.

## Conocimientos Aplicados
* Uso de métodos de arreglos (`push`, `filter`, `map`) para gestionar la lista de películas.
* Delegación de eventos para optimizar la interacción con elementos creados dinámicamente.
