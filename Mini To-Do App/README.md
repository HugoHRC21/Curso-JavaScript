# Mini To-Do App - CRUD Operations

Una aplicación de gestión de tareas que permite a los usuarios organizar su día a día, enfocada en la persistencia de datos y la manipulación dinámica de listas en **JavaScript**.

## Características principales
* **Gestión de Tareas:** Capacidad para añadir, marcar como completadas y eliminar tareas de forma individual.
* **Persistencia Local:** Uso de `localStorage` para que las tareas no se borren al refrescar la página.
* **Filtros Dinámicos:** Clasificación de tareas por estado (todas, pendientes, completadas).

## Tecnologías utilizadas
* **JavaScript (ES6+):** Lógica para la creación de nodos de lista dinámicos y manejo del almacenamiento local.
* **HTML5 & CSS3:** Uso de checkboxes personalizados y diseño limpio para facilitar la lectura.
* **DOM API:** Métodos como `appendChild`, `remove` y `querySelector` para una interfaz reactiva.

## Particularidades
* Dominio de las operaciones **CRUD**.
* Manejo del estado de la aplicación (saber qué tareas están hechas y cuáles no).
* Uso de almacenamiento en el navegador para mejorar la experiencia de usuario (UX).
