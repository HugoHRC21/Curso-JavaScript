# Password Generator - Security & String Manipulation

Una herramienta interactiva diseñada para generar contraseñas seguras y personalizadas, enfocada en la robustez algorítmica y la experiencia de usuario en **Vanilla JavaScript**.

## Características principales
* **Personalización Total:** Permite elegir la longitud de la contraseña y el tipo de caracteres (mayúsculas, minúsculas, números y símbolos).
* **Algoritmo de Aleatoriedad:** Implementación de lógica para asegurar que la contraseña sea impredecible y cumpla con estándares de seguridad.
* **Copiado al Portapapeles:** Funcionalidad integrada para copiar la contraseña generada con un solo clic mediante la Clipboard API.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de métodos de strings y ciclos complejos para la construcción dinámica de la clave.
* **HTML5 & CSS3:** Interfaz moderna con controles deslizantes (sliders) y validaciones visuales.
* **DOM Events:** Manejo de eventos en tiempo real para actualizar la fuerza de la contraseña.

## Desafíos Técnicos
* Combinación dinámica de múltiples conjuntos de caracteres según las preferencias del usuario.
* Asegurar una distribución equitativa de caracteres para evitar patrones predecibles.
