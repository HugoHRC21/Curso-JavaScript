# Propiedades de Texto - Dynamic Styling Engine

Una herramienta interactiva desarrollada con **Vanilla JavaScript** que permite manipular en tiempo real las propiedades visuales de un texto, demostrando el control dinámico del CSS mediante el DOM.

## Características principales
* **Manipulación en Tiempo Real:** Cambios instantáneos de fuente, tamaño, color y alineación del texto.
* **Interfaz de Control:** Panel de mandos intuitivo con selectores y botones para personalizar la experiencia visual.
* **Feedback Visual:** Renderizado inmediato de los estilos aplicados sin necesidad de recargar la página.

## Tecnologías utilizadas
* **JavaScript (ES6+):** Uso de la propiedad `.style` del DOM para inyectar CSS dinámicamente según la interacción del usuario.
* **HTML5 Form Elements:** Implementación de selectores (`select`), inputs de color y rangos para capturar preferencias.
* **CSS Moderno:** Diseño de un lienzo (canvas) de texto limpio y legible.

## Conocimientos Aplicados
* Manejo de eventos de cambio (`change`) e input para una respuesta fluida.
* Gestión de clases de CSS y estilos en línea mediante JavaScript.
* Comprensión de la jerarquía de estilos y especificidad.
