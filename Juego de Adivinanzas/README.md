# Number Guessing Game - Logic & State Management

Un juego de lógica donde el usuario debe adivinar un número generado aleatoriamente, poniendo a prueba el manejo de estados y la validación de datos en **JavaScript**.

## Características principales
* **Generación Aleatoria:** Uso de algoritmos matemáticos (`Math.random`) para asegurar una experiencia distinta en cada partida.
* **Validación de Entradas:** Control de errores para asegurar que el usuario ingrese números dentro del rango permitido.
* **Sistema de Intentos:** Lógica programada para limitar las oportunidades del usuario y gestionar el estado de "Game Over".

## Tecnologías utilizadas
* **Vanilla JavaScript:** Lógica de comparación, contadores de intentos y manipulación dinámica del DOM.
* **CSS3:** Animaciones y transiciones suaves para mejorar el feedback visual al usuario.
* **HTML5:** Estructura clara y accesible para el formulario de entrada.

## Conceptos Aplicados
* Manejo de la función `Math.floor()` y `Math.random()`.
* Condicionales anidados para dar pistas al usuario ("Más alto", "Más bajo").
* Actualización de texto e imágenes en tiempo real según el resultado.
